# Simon Blackburn: *Think*

> A Cambridge philosopher's introduction that **teaches problems through the great texts**. Each chapter takes a problem and works through how Descartes, Hume, Berkeley, Leibniz, Kant and others argued it. It is recommended as pre-reading by Oxford (Somerville College's 2025 PPE letter).

## The path (8 chapters)
| # | Chapter | Anchor texts / thinkers |
|---|---|---|
| — | Introduction | What philosophy is; how to argue |
| 1 | Knowledge | Descartes's *Meditations*, scepticism, the cogito |
| 2 | Mind | Dualism, other minds, functionalism |
| 3 | Free Will | Determinism, Hume's compatibilism |
| 4 | The Self | Locke and Hume on personal identity |
| 5 | God | Ontological, cosmological and design arguments; Hume's *Dialogues* |
| 6 | Reasoning | Induction (Hume), probability, logic |
| 7 | The World | Primary and secondary qualities, Berkeley, Kant |
| 8 | What to Do | Ethics: egoism, relativism, Kant, utilitarianism |

## Chapter anatomy
- The problem stated → a key passage from a classic text, quoted and dissected → objections and replies, including modern ones → Blackburn's own judgment.

## Takeaways for LeetLit
- **"Problem × primary text" fusion** resolves the history-vs-problems dilemma. Each node is a problem, and each problem's exercises use a canonical passage. This is the Oxford tutorial model in book form.
- Blackburn's ordering puts **knowledge first and ethics last,** the same order as Crash Course and Cambridge IA.
