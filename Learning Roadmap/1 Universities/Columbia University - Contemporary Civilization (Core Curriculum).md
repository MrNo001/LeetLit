# Columbia University: Contemporary Civilization ("CC")

> Founded in 1919, CC is the Core's moral and political philosophy sequence. It is a year of primary sources on "the communities people build (political, social, moral, and religious) and the values behind them," read critically rather than reverently.

## The path
Currently required authors, in roughly chronological order:

**Ancient and medieval:** Plato → Aristotle → Epicurus → (Bible, Qur'an) → Augustine → Ibn Khaldun → Christine de Pizan

**Early modern:** Machiavelli → Luther → Descartes → Hobbes → Locke → Rousseau → Adam Smith → Kant → Mary Wollstonecraft

**19th century:** Tocqueville → Frederick Douglass, Elizabeth Cady Stanton, Sojourner Truth, David Walker → J. S. Mill → Marx → Nietzsche

**20th century:** Freud → W. E. B. Du Bois → B. R. Ambedkar → Hannah Arendt → Gandhi → Frantz Fanon → Martin Luther King Jr. → Michel Foucault → Simone de Beauvoir → Barbara Fields → Combahee River Collective

### Thematic units woven through the chronology
1. Epicureanism and Stoicism
2. Medieval rationalism and mysticism
3. The Conquest of the Americas
4. Revolutions and rights
5. Race, gender, and sexuality
6. Climates and futures

## How a session works
- Seminar discussion of the assigned primary text. Students come having read the original, not a summary.
- The course aims to "engage with [authors] critically" rather than endorse them. Discussion is argumentative: reconstruct the argument, then test it.
- Thematic units cluster texts that answer each other, so earlier readings get re-read in light of later ones.

## Takeaways for LeetLit
- **A chronological spine with thematic "units" layered on top.** The same text list can be traversed by date or by theme. This suggests a roadmap with two views over one graph.
- **Primary text first, with no textbook mediation.** If LeetLit serves summaries, it should treat them as scaffolding toward the original rather than a replacement.
- **Writing cadence:** three papers a semester is a steady practice loop (read → discuss → write).
